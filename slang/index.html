How to use this site

Open a list that fits the chat you are reading, or use the A to Z to look up one word. Each word has a short plain meaning and an example sentence, so you can see how it is used, not only what it means.

New to the subject? Read how slang spreads, then how to check an unknown word safely. If you are a parent, there is a calm guide on slang for parents; for work messages see slang at work and texting etiquette.

We explain words as they are used, and we leave out slang that is mainly abusive. This site is independent.
