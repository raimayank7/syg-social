WhatsApp link not working: how to fix it

Why a wa.me link may open the wrong chat, show an error or do nothing: wrong number format, missing WhatsApp, encoding problems and how to fix each of them.

A click-to-chat link has few moving parts, so problems are easy to find. Go down this list from the top.

  1. Check the number. It must have the country code first, and no plus sign, zeros, brackets or dashes. Compare it with the examples on the number format page.
  2. Check that the number has WhatsApp. A link only opens a chat for a number with an active WhatsApp account.
  3. Check that WhatsApp is installed. On a computer without the app, the link opens WhatsApp Web, and you need to sign in.
  4. Check the message. If the text is cut off, an ampersand or a hash may not be encoded. Rebuild the link in the link maker, which encodes the message for you.
  5. Check for spaces. A link with a space in it breaks in some apps. Copy the full link without extra spaces.
  6. Check the app that shows the link. Some apps open links in a built-in browser and ask to open WhatsApp. Choose open in WhatsApp.

When it opens the wrong chat

This almost always means the number is wrong, often a leading 0 or a doubled country code.

When nothing opens

Try the same link on another phone, and on WhatsApp Web. If it works there, the problem is the first device. If not, rebuild the link.

Still stuck? See the official page at WhatsApp's help.

Questions people ask

Why is part of my message missing?

A symbol such as & or # was not encoded. Our link maker encodes every message, so rebuild the link there.
