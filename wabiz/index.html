How to start

Install the WhatsApp Business app on a number you use for the shop, fill in the business profile, then set a greeting and your first ten quick replies. Add labels so you can see each order's stage, and follow the order workflow.

To give customers a link or QR code that opens a chat with you, use the WhatsApp link maker. We do not offer bulk sending.
