How to use this site

Pick the subject closest to yours and read the ideas. Each one says how to make the update in a sentence. Choose five, write them in your own words and post them over two weeks.

New to channels? WhatsApp describes them as one-way: followers read, react and vote in polls, but cannot reply. Start with how channels work and how to create one. If you want a conversation instead, see channel, group or status.
